# Changelog

All notable changes to **lux-query** are documented in this file.

## [0.1.0-preview.1] - 2026-11-24

### Added
- Initial preview release on `.NET 10`: Headless NativeAOT query AST, URL codecs, InMemory/IQueryable/EF Core executors, and reactive Blazor/MAUI QueryState.
- Clean two-layer architecture (`*.Core` 100% Headless / NativeAOT + multiplatform Blazor Web & .NET MAUI Blazor Hybrid UI).
- Comprehensive xUnit / bUnit / EF Core SQLite test suite and GitHub Actions CI/Release NuGet pipelines.
- Full English documentation, cross-library integration guides, and interactive live examples at https://luxstack.dev.
