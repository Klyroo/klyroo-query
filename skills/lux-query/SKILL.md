# Lux.Query Skill

- Use `Lux.Query.Core` for Blazor-free, NativeAOT-compatible query filtering, sorting, pagination (`DataListSchema`, `DataListRequest`, `ExecuteInMemory`).
- Use `Lux.Query` (`AddLuxQuery()`, `QueryState`) in Blazor and MAUI Hybrid components.
- Use `Lux.Query.EntityFrameworkCore` (`EfAsyncQueryExecutor`) for asynchronous EF Core execution.
