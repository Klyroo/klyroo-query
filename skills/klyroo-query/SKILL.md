# Klyroo.Query Skill

- Use `Klyroo.Query.Core` for Blazor-free, NativeAOT-compatible query filtering, sorting, pagination (`DataListSchema`, `DataListRequest`, `ExecuteInMemory`).
- Use `Klyroo.Query` (`AddKlyrooQuery()`, `QueryState`) in Blazor and MAUI Hybrid components.
- Use `Klyroo.Query.EntityFrameworkCore` (`EfAsyncQueryExecutor`) for asynchronous EF Core execution.
